# Installation guides / 安装指南

One ZIP includes all 15 interface languages. The extension follows Chrome’s display language by default. You can switch languages under **All settings → Language**.

同一安装包包含 15 种界面语言。默认跟随 Chrome，也可以在「完整设置 → 语言」手动切换。
