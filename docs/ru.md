# Sim Companies VWAP на складе

[Выбрать язык](README.md)

Расширение показывает средневзвешенную по объёму цену (VWAP) и цену за единицу со скидкой для товаров на складе с учётом качества. По умолчанию используются предыдущие сутки по UTC. Для официальных дневных графиков по качеству нужен игровой статус Supporter.

## Установка и обновление

1. Скачайте `warehouse-vwap-v*.zip` из раздела **Assets** и распакуйте архив. [Последняя версия](https://github.com/Linjun-Chen/sim-companies-warehouse-vwap/releases/latest)
2. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**. Выберите папку `warehouse-vwap` с файлом `manifest.json`.
3. Войдите в игру и откройте склад. Разверните **VWAP на складе**, чтобы увидеть цены товаров в наличии, или откройте карточку товара для просмотра цен по качеству.

Для обновления замените файлы в папке, из которой уже загружено расширение. Нажмите значок перезагрузки на карточке установленного расширения, затем обновите вкладку склада. При использовании той же папки настройки и сохранённые цены останутся доступными.

## Скидки и язык

На странице товара нажмите процент рядом с ценой со скидкой. Можно задать скидку для товара и отдельные значения для качества от Q0 до Q12. Пустое поле наследует настройку вышестоящего уровня. Значение 0 означает цену без скидки. После сохранения цены пересчитываются сразу.

По умолчанию расширение использует язык интерфейса Chrome. Для смены языка откройте расширение на панели инструментов и выберите **Все настройки → Язык**.
