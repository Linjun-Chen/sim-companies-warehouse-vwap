# Sim Companies 倉庫 VWAP

[言語を選択](README.md)

倉庫にある商品の出来高加重平均価格（VWAP）と値引き後の単価を、品質別に確認できます。初期設定では UTC の前日分を表示します。ゲーム公式の品質別日足チャートには Supporter 権限が必要です。

## インストールと更新

1. **Assets** から `warehouse-vwap-v*.zip` をダウンロードして展開します。[最新版](https://github.com/Linjun-Chen/sim-companies-warehouse-vwap/releases/latest)
2. `chrome://extensions` を開き、デベロッパー モードを有効にします。解凍済みの拡張機能を読み込むボタンを押し、`manifest.json` が入った `warehouse-vwap` フォルダを選びます。
3. ゲームにログインして倉庫を開きます。「倉庫 VWAP」を開くと在庫の価格一覧が表示されます。商品詳細では品質別の価格を確認できます。

更新するときは、新しいファイルを現在読み込んでいるフォルダに上書きします。既存の拡張機能カードで再読み込みを押してから、倉庫ページを更新してください。同じフォルダを使えば、設定と保存済みの価格データを引き継げます。

## 値引きと言語

商品詳細で値引き後の価格の横にあるパーセント表示を押すと、商品全体と Q0〜Q12 の値引き率を設定できます。空欄にすると上位の設定を引き継ぎ、0 を入力すると値引きがなくなります。保存すると価格がすぐに再計算されます。

表示言語は初期設定で Chrome に従います。ツールバーの拡張機能アイコンから「すべての設定 → 言語」で変更できます。
